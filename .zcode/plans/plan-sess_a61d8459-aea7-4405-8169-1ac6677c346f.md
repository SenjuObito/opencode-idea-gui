修复 runIde 构建报错 `tsc: command not found`（webview 依赖未安装）

1. 安装 webview 依赖：在 `webview/` 目录运行 `npm ci`（依据 package-lock.json 安装 typescript/vite 等依赖）。
2. 根治 build.gradle：修改 `buildWebview` 任务（build.gradle:368-429），在执行 `npm run build` 前检测 `webview/node_modules` 是否存在，不存在则自动执行 `npm ci`，逻辑与现有 `packageAiBridge` 任务（build.gradle:456-461）保持一致。
3. 验证：重新执行 `./gradlew buildWebview` 确认构建通过，之后可正常跑 runIde。
